# 项目讲解与简历表达

本页仅描述仓库中可以运行、审阅和测试的内容，不代表已完成医院临床部署。

## 项目介绍

开发面向数字病理切片的研究分析智能体，以 Python/FastAPI 搭建切片处理服务，使用 OpenSlide 按层级读取 WSI，串联组织筛选、染色标准化、模型评分、热力图与结构化报告。Vue 工作台支持任务进度、区域坐标定位与报告追问；通过工具白名单将千问兼容大模型接入当前切片证据查询，并提供无密钥本地演示模式。

## 测试开发岗位可说明的工作

- 为上传、解析、采样、模型适配及报告链路设计自动化测试，覆盖无效格式、损坏文件、上传超限、纯背景、参数越界、缺失层级等场景。
- 设计限量网格采样验证，检查巨幅切片坐标数量、边界与覆盖口径，避免把局部采样报告成全片结论。
- 为模型工具调用构造正常响应及异常服务，验证工具白名单、证据追溯与确定性回退。
- 增加患者级划分检查和二分类指标单元测试，并通过 GitHub Actions 执行测试、代码检查和前端构建。

## 面试演示顺序

1. 点击合成样本，展示自动分析进度及五步工具轨迹。
2. 展示原图/热力图切换和区域定位，解释 level-0 坐标。
3. 询问“高分区域在哪里”，展示与报告一致的坐标和分数。
4. 导出报告，说明演示模式、覆盖率与非临床边界。
5. 展示测试中的异常链路、训练清单泄漏检查和 CI 结果。

## 需要如实区分

- 可以说实现了 PyTorch 训练与推理接口，不能据此声称训练了病理基础大模型。
- 可以说实现了启发式模糊与深色提示，不能声称已实现可靠的折叠/气泡识别。
- 可以说支持限量 WSI 读取，不能用网格单测代替数 GB 真切片吞吐测试。
- 只有提供经授权数据、实验记录与评估证据后，才可填写真实准确率、敏感度或医院落地成果。
